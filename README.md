## 面板游戏云还是 VPS 游戏云

买之前先分清两种形态：面板游戏云自带运行环境，VPS 游戏云给你一台空机器。

面板游戏云内置自研 MCSM 面板，Paper、Spigot、Forge、Fabric 都能一键跑起来，CPU 支持在线升降级，有自动备份和自带的 MySQL，全程不用 SSH。带宽固定 50Mbps 上行，这个上行比同价位 VPS 的 5M、10M 宽得多，十几个人同时在线下载整合包、跑地图不会卡在带宽上。IP 是 NAT 映射，需要在面板里手动把 25565 转发出去，照着教程走两三步。最低 1 核 2G 起步。

端口数量上，资料里有“10 个端口”和“15 个端口”两种说法，以你面板里实际显示的可转发数量为准。NAT 共享 IP 的代价是朋友要连“IP:端口”而不是裸 IP，自己人玩完全够用；要直连、要打广告拉人，得加钱换独立公网 IP。

VPS 游戏云给完整系统权限，Linux 或 Windows 自选，SSH、RDP、VNC 都能用，自己装 Java、传 jar 包、写启动脚本，一台机器上开几个服也没人拦。最低 2 核 4G 10M 起步，最高能到 8 核 32G 30M。系统选 Ubuntu Server 或 CentOS Stream 都行，省下来的内存全给 JVM；Windows Server 光系统就要吃掉 2G 内存，小配置机器上很不划算。

## 动态计费值不值

雨云有固定和动态两种计费方式。固定就是月租写死，CPU 空转还是跑满一个价。动态的基础租金很低，CPU 使用率超过 20% 的部分按“CPU 电量”日结，1 CPU 电量约等于 30% CPU 跑 1 分钟，单价 0.0005～0.001 元，系统每天还送一定免费电量。

按这个单价粗算，一台机器持续满负荷跑 24 小时约 1440 电量，折合 0.7～1.4 元/天，一个月 20～42 元。这是按资料口径推导的估算，不是官方报价，实际以账单为准。

判断规则很简单：24 小时都有人在线、CPU 长期高负载，选固定，别赌；白天没人、晚上才开几个小时，选动态，闲时几乎不花钱。反过来选错方向，一种是白付闲置月租，另一种是月底账单比固定还贵。

## 下单前把这几条退款规则看清楚

7 天无理由退款是真的，退订入口在产品控制面板里的“退订”按钮，每个账号 3 次机会。但条款里有几个例外，官方退款政策写得很明确：

- 领取过产品消费积分后，不能退；
- 参加过 1 元试用并续费后，不能退；
- 超过 7 天，不能退；
- 日付、流量包、游戏云电量、IP 增加、硬盘或套餐升级这类非月付场景，不支持退订；
- 限流套餐日流量超过 100G，自动取消 7 天无理由资格。

新购场景的退订会自动退回对应的优惠券，也就是说首月 5 折券退单后能拿回来，这点对想换机房的读者有用。另外，首月 5 折券有效期 30 天，注册绑定微信后自动到账；1 元试用每款产品限一次，部分高配机型试用价会高一点。
